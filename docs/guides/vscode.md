# Configure VS Code

1. Install the **Sonite** extension (Marketplace or VSIX).
2. Open a folder containing `.sn` files.
3. Confirm Output → **Sonite** shows the language server starting.

Optional: install the standalone CLI for terminal builds (`sn build` / `sn run`).

Details: [VS Code tooling](../tooling/vscode.md), extension README under `packages/vscode/`.
