# FFI (native libraries)

Call C ABI libraries with `extern` and `unsafe`.

```bash
cd examples/native-ffi
# build the native archive for your platform (see README)
sn run
```

Read [`examples/native-ffi/README.md`](../../examples/native-ffi/README.md), [FFI](../ffi.md), and [FFI security](../security/ffi.md).
