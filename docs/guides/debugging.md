# Debug a Sonite program

1. Build with debug info (default profile).
2. Install the VS Code extension (or use the debug adapter via `sn debug-adapter`).
3. Set breakpoints in `.sn` sources.

```bash
cd examples/debugging
sn build
```

Full guide: [Debugging](../debugging.md). Example notes: [`examples/debugging/README.md`](../../examples/debugging/README.md).
